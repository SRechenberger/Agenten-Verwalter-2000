# Chat im flachen Stil (Taiga 236)

`mockup.html` ist der Prototyp, eigenständig. Ein Umschalter zeigt Heute (rund) und Neu (flach).

## Regel
- **F1:** Keine runden Kästen mit eigener Fläche.
- **F2:** Eine 2-px-Linie links in der Farbe der Art: Nutzer `--color-border`, Session-Nachricht Master-Farbe, Rückfrage Wartefarbe, Vorschlag Akzent, Fehler rot.
- **F3:** Listen als Zeilen mit Haarlinien: Optionen einer Rückfrage, Werkzeug-Details, Karten über dem Eingabefeld.
- **F4:** Code, Diffs, Fehlertexte und Felder eckig, mit Haarlinie.
- **F5:** Knöpfe, Marken und Chips `--radius-flat` (2 px); Punkte bleiben rund. Kein Schalter.
- **F6:** Das Eingabefeld behält den Rahmen, mit `--radius-flat`.
- **F7:** Der Stil sitzt an der Quelle der Bausteine; damit sind auch die Popups des Dashboards flach.
- **F8:** Menüs, Dialoge und Popover außerhalb des Chats bleiben unverändert.
