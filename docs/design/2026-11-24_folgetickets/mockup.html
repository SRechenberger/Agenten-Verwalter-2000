auch HTML-Artefakte der Agenten (deine Wahl)

<html data-theme="light"> ← setzt die Brücke, wenn die App auf Hell steht <html data-theme="dark"> ← wenn die App auf Dunkel steht <html> ← bei System: kein Attribut

Eine Seite, die ihre Farben so schreibt, folgt damit der App:
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) {…} } und :root[data-theme="dark"] {…}. Seiten, die nur auf prefers-color-scheme hören, bleiben beim System. Die Anweisung an die Agenten bekommt dazu einen Satz.
