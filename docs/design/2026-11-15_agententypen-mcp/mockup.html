Agententypen per MCP vorschlagen Entwurf · Taiga-Story 109

Ein Agent schlägt über agent_type_propose_create oder agent_type_propose_update einen Agententyp vor. Das Werkzeug wartet; im Chat der Session erscheint ein Kasten. Gespeichert wird erst, wenn der Benutzer übernimmt. Jeder Knopf im Kasten ist klickbar; die Schritte springen direkt zu einem Zustand.
